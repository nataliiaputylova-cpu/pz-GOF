# Реалізація GOF патернів проєктування

---

## Реалізовані патерни

### Породжувальні

**Factory Method** — створення різних типів документів (Word, Excel, PowerPoint) без прив'язки до конкретних класів.

**Builder** — покрокова побудова будинку з різними параметрами (поверхи, дах, гараж, басейн).

**Singleton** — одне підключення до бази даних для всього застосунку.

### Структурні

**Adapter** — датчик температури у Фаренгейтах адаптується до інтерфейсу що очікує Цельсій.

**Facade** — система розумного будинку приховує складність керування світлом, кондиціонером та охороною.

**Decorator** — форматування тексту (жирний, курсив, підкреслення) без зміни базового класу.

### Поведінкові

**Strategy** — алгоритми сортування (Bubble Sort, Quick Sort) змінюються під час виконання.

**Observer** — інвестори підписуються на акції та отримують сповіщення про зміну ціни.

## Висновки

Кожен патерн вирішує конкретну проблему:
- **Factory Method, Builder, Singleton** — керування створенням об'єктів
- **Adapter, Facade, Decorator** — організація структури та взаємодії класів
- **Strategy, Observer** — гнучке керування поведінкою під час виконання
